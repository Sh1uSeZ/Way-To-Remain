## Flow

```
index.html                   หน้าเข้าเกม → hover ปุ่ม Start (ซูมเล็กน้อย) → คลิก → เล่นวิดีโอ intro
   ↓
lobby.html                   หนังสือเดินทาง → hover การ์ด กล้องแพนเข้าไปหา → คลิก
   ↓
stages/roi-et.html           ฉากกว้าง 3965px เลื่อนเมื่อเมาส์ชิดขอบซ้าย/ขวา → คลิกผู้เฒ่า → กล่องบทสนทนา
   ↓
stages/roi-et-ritual.html    พิธีอาบน้ำศพ (โครงว่าง รอภาพจากลูกค้า)
```

## โครงสร้างไฟล์

แยกส่วนที่ใช้ซ้ำได้ (`js/core/`) ออกจากส่วนที่ผูกกับด่านใดด่านหนึ่ง (`js/stages/`)
เพื่อให้ด่านต่อไปเขียนทับน้อยที่สุด ทุกไฟล์ยาวไม่เกิน ~80 บรรทัด

```
css/
  base.css        ฟอนต์ ตัวแปรสี ม่านดำเปลี่ยนฉาก
  title.css       หน้าเข้าเกม
  lobby.css       หนังสือเดินทาง + การ์ดเลือกด่าน
  panorama.css    ฉากกว้าง, object, hotspot, ป้ายชื่อ      (ใช้ซ้ำได้)
  dialog.css      กล่องบทสนทนา + ฉากหลังหรี่                (ใช้ซ้ำได้)
  pending.css     หน้าโครงว่างที่ยังรอภาพ
  mobile.css      ทุกอย่างที่แก้เฉพาะจอสัมผัส/จอเตี้ย รวมไว้ที่เดียว
js/
  core/
    transition.js  goTo(url) — เฟดดำแล้วเปลี่ยนหน้า          (ใช้ซ้ำได้)
    dialog.js      ระบบบทสนทนา พิมพ์ทีละตัว กดเพื่อไปต่อ      (ใช้ซ้ำได้)
    panorama.js    กล้องเลื่อนเมื่อเมาส์ชิดขอบ + ตรวจ hover    (ใช้ซ้ำได้)
    parallax.js    กล้องขยับตามเมาส์เล็กน้อย                  (ใช้ซ้ำได้)
    touch.js       ตรวจว่าเป็นจอสัมผัส, ตั้ง --app-h, ป้ายหมุนจอ
  screens/
    title.js       Start → วิดีโอ → lobby
    lobby.js       hover การ์ดแล้วแพนกล้อง
  stages/
    roi-et.js      ต่อสาย hotspot เข้ากับบทสนทนาของด่านนี้
data/
  roiet-dialog.js  บทพูดทั้งหมดของด่านร้อยเอ็ด — แก้ที่นี่ที่เดียว
assets/            ภาพและวิดีโอจากลูกค้า (ดู CREDITS.md)
```

### เพิ่มด่านใหม่

1. วางภาพลง `assets/<ด่าน>/`
2. คัดลอก `stages/roi-et.html` แล้วเปลี่ยน path กับตำแหน่ง `.obj--*` / `.hotspot--*`
3. เขียนบทพูดไว้ใน `data/<ด่าน>-dialog.js`
4. คัดลอก `js/stages/roi-et.js` แล้วแก้เฉพาะเงื่อนไขว่ากดอะไรแล้วเกิดอะไร
5. ปลดล็อกการ์ดใน `lobby.html` (เอา `card--locked` ออก ใส่ `card--live` + `data-goto`)

## การควบคุม

| หน้า | การควบคุม |
|---|---|
| หน้าเข้าเกม | กล้องขยับตามเมาส์เล็กน้อย · hover ปุ่ม Start แล้วซูมนิดหน่อย |
| Lobby | กล้องขยับตามเมาส์เล็กน้อย · hover การ์ดแล้วกล้องซูมเข้าหาเบา ๆ (1.26x) |
| ด่าน | เลื่อนฉากเฉพาะตอนเมาส์อยู่ในโซนขอบ (20% ซ้าย/ขวา) ตรงกลางฉากอยู่นิ่ง |

### บนมือถือ (เล่นได้ ไม่ได้เน้นสวย)

| หน้า | การควบคุม |
|---|---|
| ทุกหน้า | แนวตั้งจะขึ้นข้อความให้หมุนเครื่อง เกมออกแบบมาสำหรับจอแนวนอน |
| หน้าเข้าเกม | ปิด parallax แตะ Start ได้เลย |
| Lobby | แตะการ์ดครั้งแรก = กล้องซูมดูก่อน แตะซ้ำอีกครั้ง = เข้าด่าน |
| ด่าน | ลากนิ้วซ้ายขวาเพื่อเลื่อนฉาก · object ที่กดได้จะเรืองแสงค้างไว้ (ไม่มี hover) · แตะเพื่อคุย |

ลากแล้วปล่อยจะไม่นับเป็นการแตะ (กันลากแล้วเผลอเปิดบทสนทนา)

## หมายเหตุทางเทคนิค

- `--app-h` ถูกตั้งจาก `window.innerHeight` ใน `touch.js` แล้ว CSS ใช้ค่านี้แทน `100vh`
  เพราะบนมือถือ `100vh` รวมแถบ address bar ทำให้ค่าที่ CSS กับ JS ใช้ไม่ตรงกัน
- ประกาศ `color-scheme: light` ไว้เพื่อปิด auto dark mode ของ Chrome บน Android
  ที่จะกลับสีภาพลายเส้นขาวดำจนดูไม่ออก

## สิ่งที่ยังค้าง

- **บทพูดเป็นบทชั่วคราว** ที่เขียนขึ้นเองเพื่อวางระบบ รอบทจริงจากลูกค้ามาแทนใน `data/roiet-dialog.js`
- `stages/roi-et-ritual.html` ยังเป็นโครงว่าง รอไฟล์ภาพ
- ตัวอักษร "Ways to Remain" บนหน้าแรกวาดมาในไฟล์ภาพพื้นหลังอยู่แล้ว หน้าเว็บเติมเฉพาะปุ่ม Start ด้วย Playpen Sans Thai ตามที่ลูกค้าสั่ง

## รันในเครื่อง

ต้องเปิดผ่าน http เพราะเบราว์เซอร์บล็อกบางอย่างเมื่อเปิดไฟล์ตรง ๆ

```bash
python -m http.server 5173
```

แล้วเปิด http://localhost:5173
